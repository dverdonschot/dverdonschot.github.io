  • ReLift: Dense 3D Tracking as Lifted Trajectory Repair

  • HALO: Human-Grounded Granular Evaluation of Proactive Agents
    Proactive agents must decide whether, when, and how far to assist without an explicit request.
  • Apriel Voice 27B Preview: An Open Model for Speech, Reasoning, and Tool Use

  • Probing Spatial State Representations in Visual Foundation Models
    An observer sees only part of the surrounding world, yet must keep track of what lies beyond the current view.
  • On the Origin and Evolution of Training-Inference Mismatch in LLM Reinforcement Learning
    On-policy reinforcement learning for large language models assumes that training responses are sampled from the current policy.
  • CaPtain: A Pipeline for Post-Training Code-as-Policy Robot Agents
    Across coding, web, and tool-use tasks, language-model agents are now routinely trained with the same recipe: supervised fine-tuning (SFT) to learn the interface, then multi-turn reinforcement learning (RL) to master it.
  • RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory
    Recent work shows that a frozen robot policy performs far better inside an agent harness, where control code decides when to query the policy, consult vision tools, or command the arm directly.
  • CausalWAM: Learning the Causes of Actions in World Action Models
    World action models (WAMs) learn latent variables from observations and use these to both predict the evolution of the scene and to generate actions.
  • WeFair: Fidelity-Aware Alignment from Human Feedback for Personalized Query Rewriting in Short-Video Search
    Short-video search needs compact query rewriters that recover users' personalized intent from ambiguous queries under strict latency constraints.
  • FrameForge: Harnessing Priors of Video Foundation Models for Unified Image Generation
    Unified conditional image generation requires a single model to preserve different aspects of a visual input while producing a target image that follows textual guidance.

Value. value = quality / cost of a 10000 token in + 2000 token out task, with a $0.00 cost floor so free models score high without dividing by zero.

Popularity. A blend of arena votes, how many providers serve the model, HuggingFace trending and how often the model is named in the week's chatter.
