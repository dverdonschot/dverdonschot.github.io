# Dennis Verdonschot's Personal Website

A modern, framework-free static site built with plain HTML, CSS, and JavaScript.

## Features

✨ **Modern & Clean Design**
- Responsive layout that works on all devices
- Dark/light theme with system preference detection
- Smooth animations and transitions

📝 **Markdown-Powered Blog**
- Write posts in Markdown with frontmatter
- Automatic syntax highlighting for code blocks
- Reading time estimation
- Tag support

🚀 **SEO & Performance**
- Auto-generated sitemap.xml
- RSS feed for subscribers
- Open Graph and Twitter Card meta tags
- Cache-busted CSS
- Semantic HTML

♿ **Accessibility**
- Skip-to-content links
- ARIA labels
- Keyboard navigation support
- Proper heading hierarchy

## Quick Start

```bash
# Install dependencies
npm install

# Build the site
npm run build

# Serve locally
npm run serve

# Or do both
npm run dev
```

Visit http://localhost:8000 to see your site.

## Writing Blog Posts

Create a new Markdown file in `posts/` (organize by year/month if you like):

```markdown
---
title: My Awesome Post
date: 2025-01-15
description: A short description of the post
tags: [javascript, web-dev]
---

Your content here in **Markdown**!

\`\`\`javascript
console.log('Code blocks are syntax highlighted!');
\`\`\`
```

Then run `npm run build` to generate the HTML.

## Deployment

The code lives on **Forgejo** (`ewt-lab/personal-site`). GitHub Pages
serves the site, so this repository is mirrored one way to
`github.com/dverdonschot/dverdonschot.github.io`, and the GitHub
Actions workflow there builds and deploys it.

```
~/projects/personal-site
   origin  -> Forgejo   ewt-lab/personal-site        (source of truth)
   github  -> GitHub    dverdonschot/dverdonschot.github.io  (Pages mirror)
```

Work happens on Forgejo. After every push to `origin`, the mirror
runs and Pages redeploys:

```bash
# one-off
bash scripts/sync-to-github.sh

# or let the timer do it (every 30 minutes)
sudo systemctl start personal-site-sync.timer
```

The mirror is one way on purpose: Forgejo wins. A commit pushed to
GitHub by hand is overwritten by the next sync.

The site is served at **https://dennis-verdonschot.nl/**. The
`dverdonschot.github.io` address keeps working as well.

### GitHub Pages

1. Build your site: `npm run build`
2. Commit the `dist/` directory
3. In GitHub repo settings, set Pages source to the `dist/` folder
4. Your site will be live at `https://yourusername.github.io`

### GitHub Actions (Automated)

Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

## Tech Stack

- **No frameworks** - Just HTML, CSS, and vanilla JavaScript
- **Build Tools** - Node.js for the build script
- **Markdown** - `marked` for parsing, `gray-matter` for frontmatter
- **Syntax Highlighting** - highlight.js (via CDN)
- **Hosting** - GitHub Pages (free!)
