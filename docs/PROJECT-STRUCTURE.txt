🎯 WHAT TO DO FIRST:

1. Read START-HERE.md for complete guide
2. Run: npm install
3. Edit: src/index.html (replace "Your Name")
4. Edit: src/about.html (write about yourself)
5. Delete sample posts or write new ones
6. Run: npm run build
7. Run: npm run serve
8. Preview at: http://localhost:8000
9. Deploy to GitHub (see SETUP.md)

⚡ KEY COMMANDS:

npm run dev         Build + serve in one
git push            Deploy to Forgejo, then mirrored to GitHub Pages

  source of truth : Forgejo  ewt-lab/personal-site
